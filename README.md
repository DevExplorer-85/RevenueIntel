# SaaS MRR Growth Analysis Dashboard

An end-to-end data analytics project built with **Plotly Dash** and **Pandas**,
simulating a real-world SaaS revenue intelligence dashboard.

## Features

| Section | What it shows |
|---|---|
| **KPI Strip** | Current MRR, ARR run-rate, Active Customers, ARPU, Churn Rate |
| **MRR Trend** | Monthly MRR vs ARR/12 over selected range |
| **MRR Waterfall** | Net-New MRR breakdown for last 6 months |
| **MRR Breakdown** | Stacked bar: New / Expansion / Contraction / Churned |
| **MoM Growth** | Month-over-month percentage growth bars |
| **ARPU & Customers** | Dual-axis: revenue per user + customer count |
| **Cohort Heatmap** | MRR retention % by acquisition cohort (M+0 to M+11) |
| **Plan / Region Mix** | Donut chart + horizontal bar |

## Dataset

Synthetic dataset generated by `data_generator.py`:
- **400 customers** across 4 plans (Starter / Growth / Pro / Enterprise)
- **36-month simulation** (Jan 2022 – Dec 2024)
- Realistic churn rates, expansion MRR, contraction events
- Industry & region segmentation

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run dashboard
python app.py

# 3. Open in browser
# → http://localhost:8050
```

## Key Analytical Concepts Used

- **MRR Decomposition**: New / Expansion / Contraction / Churned / Net-New MRR
- **Cohort Analysis**: MRR retention heatmap by acquisition month
- **ARPU Trend**: Revenue efficiency per customer over time
- **ARR Run-Rate**: Annualised recurring revenue projection
- **Churn Rate Analysis**: Monthly customer churn by plan tier

## Tech Stack

- **Dash 2.x** — reactive web framework for Python analytics
- **Plotly 5.x** — interactive charts (waterfall, heatmap, dual-axis)
- **Pandas** — data manipulation and aggregation
- **NumPy** — simulation and statistical modelling
